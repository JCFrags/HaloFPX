# Project Skill Candidates

Purpose: project-local candidate procedures derived from reviewed HaloFPX evidence.

These skills are not globally installed and are not trusted merely because their structure validates. Promote them only after their scoped commands, evidence capture, stop conditions, and rollback behavior pass realistic validation.

- [`prepare-halofpx-fork`](candidates/prepare-halofpx-fork/SKILL.md) — local source freeze, provenance, licensing, treatment, and fork-planning gates.
- [`qualify-halofpx-strix-halo`](candidates/qualify-halofpx-strix-halo/SKILL.md) — gated single-node and dual-node build/runtime qualification with evidence and rollback controls.

The Agent Harness remains an external authority when an independently
authorized copy is available through `HALOFPX_AGENT_HARNESS_ROOT`; see
[`references/agent-harness.md`](../references/agent-harness.md). These are
project candidates, not replacements for its promotion contract.
