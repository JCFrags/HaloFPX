Target-machine evidence

Required local preflights

Order matters: license and exact identity precede downloads; hashes precede loads; base decoding precedes long-context and speculative paths.

Core gates

  1. Legal scope and access signoff.
  2. Exact revision fetch; ordered shard hash/byte verification.
  3. Tokenizer, template, config, processor and imatrix hashes.
  4. Exact runtime builds and environment inventory.
  5. GGUF metadata and split integrity.
  6. CPU and ROCm load/decode with backend tracing.
  7. Context ladder and architecture-specific state tests.
  8. Tool, multimodal and MTP tests where applicable.
  9. Reference quality comparison and human workload decision.

Non-negotiable trace

Capture per-node backend assignment and fail the test when an acceptance plan forbids CPU fallback. A successful output without a trace is insufficient ROCm evidence.

See validation/preflight_matrix.csv and validation/preflight_commands.example.json.
