# Literal claim labels

| Label | Meaning |
|---|---|
| `[NORMATIVE_API]` | Public header or versioned plugin ABI contract. |
| `[NORMATIVE_DOC]` | Official AMD/ROCm documentation. |
| `[SOURCE_IMPLEMENTATION]` | Behavior directly visible in pinned implementation source. |
| `[UPSTREAM_TEST]` | Scope and assertions of an upstream test. |
| `[MAINTAINER_STATEMENT]` | Attributed AMD/maintainer issue or PR statement; not an API contract. |
| `[MAINTAINER_REPORTED_MACHINE_EVIDENCE]` | Maintainer/PR-author reports machine execution; raw independent reproduction may be absent. |
| `[COMMUNITY_REPORTED_MACHINE_EVIDENCE]` | Community report, unmerged PR, or user-provided logs. |
| `[ISSUE_COMMENTARY]` | Discussion context without normative force. |
| `[INFERENCE]` | Reasoned applicability derived from cited mechanisms. |
| `[NEGATIVE_EVIDENCE]` | A searched-for item was not found in the audited corpus; not proof of nonexistence. |
| `[MACHINE_EVIDENCE_REQUIRED]` | Claim cannot be resolved from documentation/source alone. |
