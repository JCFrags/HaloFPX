4. Userspace runtime and compiler boundary

[UNKNOWN] These public repository heads are not proven to be the exact build inputs for AMD's Ryzen AI Software 1.7.1 binary packages.

High-level supported path

[VENDOR-ONLY] AMD's captured Linux 1.7.1 instructions require a matched package set:

  • xrt_202610.2.21.75_24.04-amd64-base.deb
  • xrt_202610.2.21.75_24.04-amd64-base-dev.deb
  • xrt_202610.2.21.75_24.04-amd64-npu.deb
  • xrt_plugin.2.21.260102.53.release_24.04-amd64-amdxdna.deb
  • ryzen_ai-1.7.1.tgz

[VENDOR-ONLY] These assets are account-downloaded and governed by AMD's package terms/EULA and third-party notices.

[MISSING] Their archive hashes were not available in this research capture.

Runtime layers

The documented model path is not “kernel driver plus arbitrary ONNX”:

  1. application or framework;
  2. ONNX Runtime or ONNX Runtime GenAI;
  3. Vitis AI / VAIML execution-provider and compiler passes;
  4. compiled/cache artifact;
  5. XRT;
  6. AMD XDNA shim;
  7. amdxdna UAPI;
  8. matched firmware.

[VENDOR-ONLY] AMD's DistilBERT example instantiates VitisAIExecutionProvider with a VAIML configuration and cache key.

[VENDOR-ONLY] AMD's Linux LLM flow uses versioned prepared model folders and AMD deployment libraries rather than a generic GGUF interface.

Compiler output boundary

[UPSTREAM] At the low-level kernel contract, an NPU workload contains an array overlay and ctrlcode, both generated by the NPU compiler.

[UPSTREAM] ctrlcode orchestrates the overlay and encodes DMA operations between host DDR and local memory.

[INFERENCE] Open Peano/IRON source availability does not make arbitrary ONNX deployment turnkey. The documented ONNX graph importer, quantization, partitioning, compiled artifacts, and supported package integration remain AMD-release-specific.

Packaging consistency

[VENDOR-ONLY] AMD recommends building XRT from the submodule matched to the XDNA plugin source when building from source.

[VENDOR-ONLY] AMD documents both an upstream/staging module and a legacy module in its plugin packages.

[DECISION] A local experiment must select exactly one driver/firmware/runtime lineage and record the package and module source. Hybrid mixing is an automatic fail.

Decision: keep excluded See manifests for exact source pins, labels, licenses, and hashes.
