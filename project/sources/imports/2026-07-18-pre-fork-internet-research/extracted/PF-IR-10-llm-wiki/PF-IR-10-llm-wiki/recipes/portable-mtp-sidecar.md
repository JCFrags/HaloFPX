# MTP / model-assisted speculative artifact recipe

**Claim labels:** `UNEXECUTED-EVIDENCE`, `QUALIFICATION-REQUIRED`, `OPEN-QUESTION`  
**Accepted payload status:** no MTP, EAGLE, DFlash, or external draft-model weights are bundled.

The pinned upstream documentation lists `draft-mtp`, draft-model, EAGLE-3, DFlash, and model-free n-gram modes. The upstream documentation references publisher model repositories, but PF-IR-10 did not establish a minimal exact artifact with a complete redistribution and conversion evidence chain suitable for storage in this corpus.

The accepted speculative fixture is therefore **model-free `ngram-simple`** using the already generated tiny target model after that model is qualified. Its oracle is semantic equality with non-speculative greedy output, plus a protocol assertion that speculation was enabled; performance or accepted-draft count is not an exact oracle.

To add MTP later:

1. Identify an exact publisher checkpoint and license allowing redistribution, conversion, storage, and execution.
2. Capture the publisher revision, all source files, license text, conversion command, converter commit, dependency lock, and output SHA-256.
3. Prove tokenizer/embedding compatibility with the exact target model.
4. Compare target-only and MTP continuations under greedy decoding; token sequence must match exactly.
5. Treat draft acceptance counts and timings as diagnostic, not semantic oracles.
6. Submit the exact generated bytes for human manifest approval.
