# License evidence

`llama.cpp-LICENSE.txt`, `ROCmFPX-LICENSE.txt`, and `CachyLLama-LICENSE.txt` are exact text captured from each pinned repository revision; all three had Git blob SHA-1 `e7dca554bcb802f98408383a864404e3aa4eacca`. `ROCmFPX-THIRD_PARTY_NOTICES.md` is captured from the pinned ROCmFPX revision. Self-generated corpus files use `CC0-1.0.txt`. `hashes.json` binds each captured license/notice file to its exact candidate revision, source Git blob SHA-1, local SHA-256, and byte length. Selected literal upstream source ranges under `evidence/raw/source-ranges/` use the matching MIT license evidence.

These records support redistribution of the files actually bundled here. They do not grant rights to third-party model weights excluded by `manifests/excluded-assets.json`.
