# Synthetic generator determinism review

- **Source:** `tests/test-llama-archs.cpp` at the pinned llama.cpp commit.
- **Claim:** `INFERENCE` + `UNEXECUTED-EVIDENCE`.
- **Finding:** tensor seeding uses C++ `std::hash<std::string>` and values use `std::normal_distribution`; neither provides a portable byte-for-byte oracle across standard-library implementations.
- **Disposition:** retain upstream source as evidence only; use `recipes/generate_assets.py`, SplitMix64, and an exact power-of-two F32 palette for accepted generated bytes.
