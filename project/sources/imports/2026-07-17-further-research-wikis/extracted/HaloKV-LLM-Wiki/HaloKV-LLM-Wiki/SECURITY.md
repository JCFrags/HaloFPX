# Security policy for this research package

This package contains a protocol proposal, not a deployed service. Security findings in the design should be documented with affected assets, required attacker capability, protocol state, expected invariant, impact, and proposed control.

Do not place credentials, tenant data, real cache objects, model weights, private endpoints, or production certificates in issues, examples, corpora, or traces. Use synthetic identifiers and zeroed digests. See `wiki/Security-Threat-Model.md` for the current threat model.
