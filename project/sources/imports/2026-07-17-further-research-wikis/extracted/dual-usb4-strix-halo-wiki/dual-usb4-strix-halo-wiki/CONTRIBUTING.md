# Contributing

Updates should preserve the distinction between upstream facts, platform observations, inferences, and heuristics. For any material change:

1. Add or update a primary source in `data/source-index.json` and `docs/16-references.md`.
2. Record the exact kernel, iproute2, llama.cpp, firmware, board, and cable versions.
3. Attach a topology capture generated by `scripts/capture-topology.sh`.
4. Include isolated-link and simultaneous-link measurements, not only aggregate results.
5. State whether results are TCP, MPTCP, bond, USB4STREAM, or an out-of-tree transport.
6. Run `scripts/validate-wiki.sh` before publishing.
