# Security

The included probe and benchmark scripts are intended for two directly connected, trusted systems. Review commands before execution.

Do not expose benchmark listeners to untrusted networks. Bind services to the dedicated USB4 interfaces, use host firewalls, and avoid placing model weights, prompts, or generated output in public shares. The repository contains no credentials and expects none.

Report a security issue privately to the repository owner rather than publishing exploit details in an issue tracker.
