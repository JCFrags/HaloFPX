## Phase 0 — freeze compatibility contracts

Before touching upstream files:

1. Record type IDs and `sizeof(block_*)` assertions.
2. Generate golden quantize/dequantize vectors for every format and endpoint.
3. Capture GGUF load/round-trip fixtures.
4. Capture CPU/HIP/Vulkan operation matrices and real-model coherency prompts.
5. Capture strict-MTP target-equivalence and cache-restart fixtures.

These contracts exist across the fork’s enum, block headers, reference implementations, backend tests, and server tests. ## Phase 4 — qualification

The release gate should require:

- CPU golden vectors and quantizer round trips;
- HIP and Vulkan operation matrices;
- packed FP6 unaligned copy;
- Strix real-model coherency;
- strict MTP target equivalence;
- disk-cache restart/corruption tests;
- RPC target+draft multi-context and local-iGPU-plus-remote-device tests;
- performance comparison against the current fork with full environment manifest.

The evidence roots for these gates already exist in the fork and upstream fixes. [S-BACKEND-TEST](https://github.com/charlie12345/ROCmFPX/blob/a5605a72768c6562241b248e268e33dc92787394/tests/test-backend-ops.cpp) [S-C-62F](https://github.com/charlie12345/ROCmFPX/commit/62f7508b12c6b8510fd7a77dfc5d9519fa026d82) [S-ROCMFPX-CI](https://github.com/charlie12345/ROCmFPX/blob/a5605a72768c6562241b248e268e33dc92787394/.github/workflows/check-rocmfpx.yml) [S-C-7D7](https://github.com/charlie12345/ROCmFPX/commit/7d7b06bc5e6fd4a128af8efa954caa7409376a79) [S-SERVER-TEST](https://github.com/charlie12345/ROCmFPX/blob/a5605a72768c6562241b248e268e33dc92787394/tools/server/tests/unit/test_prompt_cache_disk.py) [S-RPC-MTP-FIX](https://github.com/ggml-org/llama.cpp/commit/c3e9ade6dd3ff2a1ceafd2d59062634715b472c4) [S-RPC-IGPU-FIX](https://github.com/ggml-org/llama.cpp/commit/1738129bee5c81b06fa1850daf3f958813c76f5f)

## Phase 5 — patch governance

Maintain three explicit upstream relationships:

- `UPSTREAM_BASE` — one pinned llama.cpp SHA;
- `ROCMFPX_FORMAT_ABI` — versioned extension ABI and golden vectors;
- `ROCMFPX_PATCHSET` — small ordered commits with one subsystem per patch.

Close superseded draft PRs and require every future shared-file patch to state whether it is format-owned, hardware-owned, policy-owned, or a temporary upstream backport.
