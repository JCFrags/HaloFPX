# Configuration schemas

These schemas normalize observed shell/CLI/C++ settings and the proposed ROCmFPX target design. They do not claim that the assessed repositories consume JSON configuration natively.

- `llama-ai-runner.schema.json`: observed parent defaults/overrides.
- `cachyllama-server-cache.schema.json`: observed component fields.
- `rocmfpx-persistent-cache-port-plan.schema.json`: proposed target contract.
