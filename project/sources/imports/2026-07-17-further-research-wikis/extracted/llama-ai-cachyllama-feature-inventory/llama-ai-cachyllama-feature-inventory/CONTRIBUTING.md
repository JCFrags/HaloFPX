# Contributing to this inventory

1. Keep every claim commit-pinned.
2. Add an evidence record before adding or changing a feature behavior.
3. Do not cite a moving branch in place of an exact commit.
4. Mark source-observed behavior, documentation intent, implementation-gap inference, and porting recommendation separately.
5. Preserve the maturity and decision rubrics.
6. Update CSV, JSON, Markdown, static UI data, and checksums together.
7. Do not convert local benchmark notes into universal performance claims.
8. Review licensing before copying source into a target repository.
