## Authority chain

1. Exact current source and commit have the highest technical precedence.
2. Machine evidence and immutable receipts follow source authority.
3. Accepted decisions define approved project choices.
4. The Wiki explains source-backed context.
5. Working guidance routes workers to the applicable authority.
