# HaloFPX LLM Wiki

This is the target wiki tree. Merge completed research-agent outputs into the exact numbered category and section paths.

## Authority model

Pages explicitly label verified facts, measurements, inferences, assumptions, recommendations, and open questions. Applicability is versioned. The root manifests and section registries determine stable paths; a page is not authoritative merely because it is newer.

## Core ledgers to maintain

- glossary and naming;
- sources;
- assumptions;
- open questions;
- decisions and ADRs;
- experiments and measured results;
- compatibility matrices;
- risks;
- implementation status.
