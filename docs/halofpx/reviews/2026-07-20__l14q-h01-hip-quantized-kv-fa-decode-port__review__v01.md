## Findings

1. **P2 maintenance gate:** the D128 and D256 instance files identify themselves
   as autogenerated, but `generate_cu_files.py` still emits only the ordinary
   declaration. A generator run would delete all four guarded H01
   instantiations. Resolve this before release or any generator run through an
   admitted generator change or deterministic preservation contract.
2. **P3 performance risk:** the target-native loader dequantizes two elements at
   a time. A wider chunk design may improve throughput, but only a measured,
   separately reviewed optimization should change it.
3. **Open gate:** final G9/G10 non-inferiority, broader telemetry, and D256
   model-level performance remain future qualification work.
