Status: accepted contract milestone; backend implementation and node mutation
have not begun.

ADR-0018 freezes the first non-synthetic storage lane as a standalone,
Linux-only, `EXCLUDE_FROM_ALL` laboratory backend. It admits only an explicitly
preflighted disposable loopback root and returns process-crash-scoped lab
observations that cannot convert any L05m/L05n synthetic proof or authorize
material, anchor, provider, server, cache, restore, or inference behavior.

The normative CDDL and independent standard-library oracle freeze the root
marker, exact `HEAD` selector, immutable registry envelopes, 512 one-shot
attempt records, terminal records, sticky quarantine, credential package,
purpose-separated domains, path-policy commitment, and exact ADR-0013 to
ADR-0014 H-to-H-plus-one transition. The final checker passes eight fixed
fixtures and 3,260 byte, truncation, domain, credential, schema, recomputed-tag,
cross-field, and fully authenticated invalid-transition mutations.

Read-only nimo-2 inventory selected that host for the future disposable test
because it has adequate headroom. No directory, loop device, mount, key,
service, model, cache, or other node state was changed by this milestone.
