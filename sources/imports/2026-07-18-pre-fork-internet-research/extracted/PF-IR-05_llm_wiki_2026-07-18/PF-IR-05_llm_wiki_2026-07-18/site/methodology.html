Evidence method

Methodology

Only complete LFS/Xet pointer sets become exact artifact totals. Rounded UI sizes remain rounded.

Four evidence planes

Publisher
Immutable publisher model, config, tokenizer/template behavior, tool behavior, and license.
Converter
Immutable GGUF repository, selected quant path, shard pointer data, lineage, imatrix statements.
Static source
Exact llama.cpp/ROCmFPX source revisions, graph and operator presence.
Local validation
NOT_RUN: download, hash, load, execution, context, quality, backend trace.

Exactness rules

Full 40-hex revisions are mandatory. Branch names and moving tags are rejected by the refresh script. Missing values use the literal UNAVAILABLE. A known exact subtotal is not an exact total.

Catalog result

No imported catalog was mounted. The baseline was reconstructed and this limitation is recorded rather than concealed.
