# Manifests

- `sources.csv`: source identifiers, pins, paths/URLs, PCI applicability, access dates, local captures, licenses, and upstream blob IDs.
- `claims.csv`: literal claim labels and evidence mapping.
- `support-boundary.csv`: support classification by technical layer.
- `versions.json`: exact research pins and AMD package names.
- `vendor-packages.csv`: gated package inventory and missing-hash state.
- `licenses.csv`: license/terms boundary.
- `role-evaluation.csv`: bounded-role disposition.
- `access-log.csv`: source access method and date.
- `exact-source-verification.json`: recomputed Git blob IDs for exact raw files.
- `files.sha256`: complete bundle integrity manifest.
- `validation.json`: artifact validation results.
