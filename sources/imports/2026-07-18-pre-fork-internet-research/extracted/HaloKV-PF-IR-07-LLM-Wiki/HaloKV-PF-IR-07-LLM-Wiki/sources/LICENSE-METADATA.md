# Source license metadata

This file records source-level licensing signals; it is not legal advice and
is not a relicensing instrument.

| Source family | License / notice retained | Bundle treatment |
|---|---|---|
| Linux kernel documentation | Linux tree `COPYING` plus `Documentation/process/license-rules.rst`; source files are from the Linux documentation tree. | Copied notices are in `sources/licenses/`. Preserve source notices when redistributing. |
| cryptsetup | `COPYING` from cryptsetup 2.8.6. | Copied in `sources/licenses/`. |
| LUKS2 format specification | Document states Creative Commons Attribution-ShareAlike 4.0 International. | PDF and repository license file are preserved. Attribution and ShareAlike obligations remain applicable. |
| systemd `crypttab.xml` | Source carries `SPDX-License-Identifier: LGPL-2.1-or-later`. | The full systemd LGPL text is preserved; the XML itself is referenced but not byte-preserved due the documented transport limitation. |
| NIST publications | Each publication carries its own front matter and notices. | PDFs are preserved without alteration. Consult each publication and NIST terms for reuse conditions; this bundle makes no blanket public-domain assertion. |
| IETF RFCs | Each RFC contains its document-specific IETF Trust copyright and legal-provisions notice. | Raw RFC text is preserved, including embedded notices. |
| HaloKV synthesis in this bundle | Original analysis generated for PF-IR-07. | See root `LICENSE-SYNTHESIS.txt`. Third-party sources remain under their own terms. |
