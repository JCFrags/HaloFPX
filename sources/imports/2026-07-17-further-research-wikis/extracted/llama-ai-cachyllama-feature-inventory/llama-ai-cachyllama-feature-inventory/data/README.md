# Machine-readable data

- `feature-inventory.json` — complete structured feature records and rubrics.
- `feature-inventory.csv` — flat feature table with exact repositories, commits, evidence IDs, and URLs.
- `retain-redesign-reject.csv` — decision-focused table.
- `evidence.json` / `evidence.csv` — evidence catalog.
- `feature-evidence.csv` — normalized feature-to-evidence join.
- `source-files.csv` — deduplicated exact source paths.
- `summary.json` — counts used by the static Wiki.
