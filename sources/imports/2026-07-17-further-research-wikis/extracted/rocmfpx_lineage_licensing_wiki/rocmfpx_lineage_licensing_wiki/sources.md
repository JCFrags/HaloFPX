## Source-use rules

1. Prefer immutable commit/blob URLs over branch URLs.
2. Record every access date and exact commit in the machine-readable ledger.
3. A GitHub fork-network object being retrievable under another repository does not by itself prove ancestry.
4. A local remote name in a commit message does not identify a repository URL.
5. Official license text controls over summaries; this wiki does not replace counsel.

Machine-readable source records are in [`data/source_ledger.csv`](data/source_ledger.csv).
