# Glossary

**Approved profile** — reviewed, immutable numeric or distributional limits scoped to exact provenance.

**Capability evidence** — machine-readable proof that a binary does or does not expose a feature.

**Candidate** — the fork/build being evaluated; never allowed to overwrite its oracle.

**Cold evaluation** — prompt/model execution without reusing a cache entry.

**Exact lane** — all controls permit equality of bytes, tokens, text, or structure.

**Fixture lock** — local paths and SHA-256 values resolving logical fixture IDs.

**MTP / NextN** — embedded multi-token prediction capability used as a speculative draft mechanism.

**Native test** — a test supplied by the pinned source repository and run without weakening its assertion.

**Normalized error class** — versioned adapter mapping of fork-specific failures into a small semantic class set.

**Observation** — one case/fork/build/lane result plus complete provenance and artifact digests.

**Oracle** — the rule deciding whether a valid observation conforms.

**Promotion** — protected process turning proposed evidence into an approved reference/profile.

**Reference fork** — normally pinned upstream for shared semantics; a fork-specific CPU path only for a feature absent upstream.

**ROCmFPX** — experimental fork-specific low-bit formats and kernels aimed at AMD platforms.

**RPC** — llama.cpp remote backend mechanism; tested only on isolated networks.

**State/cache rejection** — refusal to activate incompatible, corrupted, unauthorized, expired, or incomplete serialized state.

**Uncalibrated** — evidence may be recorded, but no numeric/distributional pass/fail gate exists.

**Warm/cold page** — persistent cache tiers outside the actively resident hot set.
