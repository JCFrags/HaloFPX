# Source registry

This directory stores source metadata, claims, access dates, and stable source IDs. It intentionally does not mirror copyrighted pages or issue bodies.

- `source-registry.json` — canonical machine-readable registry
- `source-registry.yaml` — human-diffable equivalent
- `source-registry.csv` — spreadsheet-friendly view

The rendered source page is [`docs/sources.md`](../docs/sources.md).
