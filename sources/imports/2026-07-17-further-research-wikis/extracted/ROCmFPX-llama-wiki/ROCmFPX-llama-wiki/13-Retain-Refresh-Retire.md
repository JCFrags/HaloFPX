## RETAIN definition

Retained items are the compatibility and product contracts that define ROCmFPX: format IDs/bytes, CPU reference behavior, backend mathematical semantics, Strix qualification, and fork-only server behavior. A retained capability can still require code changes when upstream interfaces move. ## REFRESH definition

Refreshed items live in shared upstream files or depend on moving upstream APIs. The implementation procedure is **copy current upstream first, then re-port a minimal, test-backed ROCmFPX delta**. Merge-forwarding the old shared file is explicitly not the recommended procedure.
