RETAIN definition

Retained items are the compatibility and product contracts that define ROCmFPX: format IDs/bytes, CPU reference behavior, backend mathematical semantics, Strix qualification, and fork-only server behavior. A retained capability can still require code changes when upstream interfaces move. S-QT-ENUM-FORK S-ROCMFP4-H S-ROCMFPX-H S-ROCMFPX-CI S-C-7D7 S-C-B56

REFRESH definition

Refreshed items live in shared upstream files or depend on moving upstream APIs. The implementation procedure is copy current upstream first, then re-port a minimal, test-backed ROCmFPX delta. Merge-forwarding the old shared file is explicitly not the recommended procedure. S-UP-HEAD S-MMVQ S-VULKAN S-SPEC-UP S-SERVER-CTX

RETIRE definition

Retired patches are superseded generic implementations, copied backend snapshots, packaging/WebUI/parser fixes, duplicate draft PRs, or non-technical metadata. They may remain in git history but should not remain in the maintained extension series. S-UP-PR25395 S-C-807 S-C-FF8 S-C-01D S-PR29 S-PR30 S-PR28
